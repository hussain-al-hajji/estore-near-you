# دكان الحي

**متاجر إلكترونية من حيّك.** منصة تعرض المتاجر الإلكترونية حسب موقعها على الخريطة، حتى تكتشف المتاجر القريبة منك في مدينتك وحيّك.

- **للزوار:** خريطة في الأعلى وقائمة متاجر في الأسفل، مع فلترة حسب المنطقة والمدينة والتصنيف، وزر «القريبة مني».
- **لأصحاب المتاجر:** نموذج «أضف متجرك» مع خريطة مدمجة لتحديد موقع المتجر أو المخزون، أو لصق رابط خرائط قوقل.

## التشغيل محليًا

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

بدون إعداد، يعمل الموقع في **وضع تجريبي** ببيانات وهمية. للربط بقاعدة البيانات عدّل `assets/js/config.js`.

## التقنيات

HTML وCSS وJavaScript بدون أدوات بناء، و[Leaflet](https://leafletjs.com) مع خرائط [OpenStreetMap](https://www.openstreetmap.org)، و[Supabase](https://supabase.com) لقاعدة البيانات.
